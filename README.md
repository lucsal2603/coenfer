# CoEnfer — Demo Concept

Demo non ufficiale del nuovo sito per **CoEnfer — Coopérative de l'Enfer** (Arvier, Valle d'Aosta), realizzata a scopo dimostrativo.

- `index.html` — sito vetrina: hero, vini con carrello demo, storia, timeline, sezione B2B, futuro multi-produttore, contatti
- `b2b.html` — area riservata B2B (demo: si entra con qualsiasi email e password)

**Stack:** HTML/CSS/JS · GSAP + ScrollTrigger · Lenis · Roboto Flex + Fraunces
